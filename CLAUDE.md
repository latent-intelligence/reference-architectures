# CLAUDE.md — reference architectures

Patterns for designing and delivering AI systems. `README.md` is the index for the whole
repository; `design/README.md` and `delivery/README.md` index each half.

- **One vocabulary.** Terms are defined once, in [`design/README.md`](design/README.md). Use
  them as defined there and link to it rather than repeat the definitions.
- **It stands alone.** No links outside this repository and no references to our codebase or
  packages. The pages are what the code is built from, not a description of it.
- **Examples are invented,** on neutral subjects (a city library, a bakery's recipes), never
  taken from client material. The README's example is the one exception: its subject is our
  own engineering know-how.
- **No dated claims about our software,** such as versions, test counts or "shipped last
  month".
- **Diagrams are plain text in code blocks.** No generator syntax.
